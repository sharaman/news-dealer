🤖 LLM-инструменты: что реально работает в проде

Проверил на своих проектах — делюсь честно:

1/ LangGraph 0.2 стабилизировал API для stateful агентов. Циклы, ветвления, персистентность состояния — теперь без боли. Если строите multi-agent систему, это ваш фреймворк. (Medium)

2/ Anthropic открыл доступ к Claude 3.5 Sonnet через API. По скорости и качеству кода обходит GPT-4o в большинстве задач из моей практики. Особенно хорош в длинных контекстах. (Telegram @ai_newz)

3/ ChromaDB 0.5 переработал хранилище — в 3x быстрее на больших коллекциях. Если используете для RAG, обновляйтесь. (Medium)

Главный вывод недели: экосистема LLM-инструментов взрослеет быстрее, чем успеваешь изучать. Фокусируйтесь на задаче, а не на фреймворке.
